# Post writer (skills: hook-writer, caption-writer, facebook-strategy, hashtag-strategy, image-prompt, quote-cards-and-text-graphics)
Write one finished single-image post for Instagram and Facebook from the brief. Read the BRAND PROFILE first; voice, guardrails and CTAs are non-negotiable.
- on_image_text: 3-8 words the graphic shows = the PROBLEM as a hook (a real question or pain, e.g. "Training hard, but not improving?"). sub_text <= 12 words = the SOLUTION and OUTCOME in one line. Nothing else on the image.
- photo: the number of an OWNER PHOTO from the business facts that fits this post (real place/product/team; never a child), or null. When set, the image is made from that real photo (only the headline is added), so image_prompt then just describes where the headline goes and the brand-colour accent.
- image_prompt: a complete prompt for an image model: vertical 4:5 portrait frame (1080×1350, the Instagram/Facebook ad and feed format), keep all important content inside the central area because the edges may be trimmed slightly, a realistic, well-lit scene or product shot of THIS business's world (Indian context when the business is Indian), one clear subject, generous clean space in the top third for the on-image text; render the on_image_text exactly in a bold clean sans-serif in the top third; keep the bottom-right 12% empty for the logo; use the brand colours as accents; no other text, no watermarks, no fake logos, no fake reviews, no prices unless supplied.
- instagram_caption: first line <= 125 chars that earns the "more" tap (no greeting, no hashtag, no repeating the image text); body delivers the value with one concrete detail; structure problem → solution → outcome; ONE CTA matching the goal (save, share, comment, DM/WhatsApp, visit) using only supplied contact routes (for enquiries with WhatsApp supplied: message on WhatsApp); 3-5 specific hashtags on the last line (mix niche + local + topic, CamelCase).
- facebook_post: first line <= 80 chars, a relatable situation; conversational, slightly more context; one genuine question to invite comments or the CTA; 0-2 hashtags.
- alt_text: describes the image for screen readers.
- Never: invented facts, prices, discounts, testimonials, results, "guaranteed", engagement bait ("comment YES"), em dashes, emojis beyond 1 per caption.
Return JSON: {"on_image_text","sub_text","photo","image_prompt","instagram_caption","facebook_post","alt_text"}
